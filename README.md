# JLPT N4·N5 학습 사이트

일본어 히라가나·한자·단어를 한 곳에서 외우려고 만든 개인 학습 사이트입니다.
서버 없이 HTML만으로 동작하며, 학습 데이터는 페이지 안에 들어 있습니다.

## 구성

- `index.html` — 목차. 히라가나 / N5 단어 / N4 단어 / 한자로 들어가는 입구
- `study.html` — 실제 학습 화면. 모든 섹션이 한 페이지 안에 있습니다
- `data/` — 단어·한자 원본 데이터 (TSV)
- `scripts/` — 원본 자료를 `study.html`로 밀어 넣는 데 쓴 스크립트

처음에는 섹션마다 페이지를 따로 뒀는데, 링크가 여러 개면 결국 안 보게 돼서
한 페이지로 합쳤습니다. 옛 주소(`flashcards.html`, `n5_vocab_flashcards.html`)는
합쳐진 위치로 넘겨주는 역할만 남아 있습니다.

휴대폰으로 보는 걸 기준으로 만들었습니다.
